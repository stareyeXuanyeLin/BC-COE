# BC-COE | 自定义服装编辑器

BC-COE（Custom Outfit Editor）是 Bondage Club 的自定义服装编辑插件。它可以把游戏中已经加载的服装图层重新组合起来，调整颜色、位置和外观，并保存为可重复使用的自定义服装。插件也提供独立衣柜，方便管理、备份和分享自己的服装搭配。

## 功能介绍

### 自定义服装编辑

- 从游戏中已经加载的服装素材里选择需要的图层，组合成一件新的自定义服装；
- 复制图层，分别调整每个图层的显示顺序、位置、透明度和颜色；
- 旋转、缩放图层，也可以对图层进行水平或垂直翻转；
- 对同一件素材的所有图层进行整体旋转、缩放、移动或翻转；
- 使用多个服装部位的自定义服装进行搭配，同时启用。

### 自定义服装衣柜

- 在插件自带衣柜中保存、启用、停用、编辑和删除自定义服装；
- 自定义服装可以按游戏服装部位分别管理；
- 单件自定义服装可以导出为字符串，用于分享或手动备份；
- 可以将整个插件衣柜导出为文件，也可以从文件中恢复；
- 导入缺少本机素材的服装时，会在导入前提示受影响的部分。

### 多人外观同步

开启共享和接收选项后，可以向同一聊天室中安装了兼容版本插件的玩家展示当前自定义外观，也可以查看对方共享的外观。

同步的是服装外观本身，不包含衣柜、图片或动态物品效果。对方没有安装相同的素材扩展时，部分服装可能无法显示。

## 安装

### 使用加载器安装（推荐）

[![安装正式版](https://img.shields.io/badge/Tampermonkey-%E2%86%95%20%E5%AE%89%E8%A3%85%E6%AD%A3%E5%BC%8F%E7%89%88-2E8B57?labelColor=1c1c1c&logo=tampermonkey)](https://raw.githubusercontent.com/stareyeXuanyeLin/BC-COE/main/dist/CustomOutfitEditor.loader.user.js)

点击按钮后，Tampermonkey 会安装插件加载器。加载器进入游戏时会自动获取正式版插件，之后通常不需要手动更新。

### 使用完整脚本安装

也可以直接安装完整脚本：

<https://raw.githubusercontent.com/stareyeXuanyeLin/BC-COE/main/dist/CustomOutfitEditor.user.js>

请只保留一种安装方式，并停用或删除其它 Custom Outfit Editor 版本，避免多个版本同时运行。

## 使用注意事项

- 原版衣柜无法保存自定义服装。自定义服装只能在插件自带的“自定义服装衣柜”中保存和管理；
- 插件使用的是游戏当前已经加载的服装素材。没有加载的素材不会出现在编辑器中；
- 删除自定义服装后，套装仓库中使用它的对应服装项也会同步移除，套装中的其它内容不受影响。删除前请确认是否仍有套装正在使用它；
- 导入整个衣柜会替换插件当前的整个衣柜，并将导入的服装设为未启用。操作前建议先导出当前衣柜备份；
- 如果导入的服装使用了本机没有的素材，对应缺失图层将无法显示；
- 自定义服装的显示仍受游戏服装部位、原版穿着状态以及素材本身限制；
- 多人同步需要双方安装兼容版本插件，并加载能够提供相同素材的扩展。动态效果和物品功能不会随外观同步。

## 版本与反馈

正式版本脚本位于仓库 `main` 分支。如果遇到安装失败、服装显示异常或衣柜数据问题，请提供游戏版本、插件安装方式以及复现步骤，便于定位问题。
