# Mirror UX 第一轮：颜色选择交互

> 状态：已解决并通过实机交互确认  
> 完成日期：2026-07-22  
> 影响范围：仅编辑器 UI；不修改衣柜 schema、远端协议、快照格式或渲染核心

## 问题

第一轮 UX 优化针对素材与图层的颜色编辑。原实现直接使用浏览器原生 `<input type="color">`，存在以下问题：

1. 选择后只显示颜色条，不显示颜色代码，不便于在图层之间复制和复用颜色；
2. 没有使用 Bondage Club 账号已有的常用颜色栏；
3. 浏览器取色弹窗缺少玩家熟悉的原版确认、取消、复制、粘贴和还原默认操作；
4. 初次接入原版面板后，面板背景透明，会与 COE 编辑器重叠，降低可读性。

## 解决方案

### 复用 BC 原版颜色面板

编辑器不再创建浏览器原生颜色输入控件，而是调用 R130 原版提供的独立颜色编辑入口：

```js
ColorPickerInit({
  heading,
  colorState: {
    colors: [currentColor],
    defaultColors: [defaultColor],
    opacity: [1],
    defaultOpacity: [1],
    editOpacity: false,
  },
  onInput: () => null,
  onExit: ({ colors }, save) => {
    // 仅在确认时写回 COE material 的颜色槽
  },
});
```

该方式与 BC 原版 `Dialog.js` 编辑独立默认颜色的用法一致，不需要伪造 Appearance Item，也不会进入 `ItemColorLoad` 对真实物品和角色画布的修改流程。

复用后自动获得：

- RGB(A) 颜色代码输入；
- 原版复制与粘贴；
- 确认与取消；
- 还原默认；
- `Player.SavedColors` 常用颜色栏；
- 常用颜色的原版账号同步行为。

### 编辑器内显示颜色代码

整体颜色与图层颜色入口改为“颜色预览块 + 颜色代码”按钮：

- 普通十六进制颜色显示规范化后的 `#RRGGBB`；
- 原版默认颜色显示 `Default`；
- 同一素材存在多个不同颜色槽时，整体入口显示“多种颜色”。

三位十六进制代码会展开并规范化，例如 `#a0f` 转换为 `#AA00FF`。

### 默认颜色语义

单层颜色面板使用对应颜色槽的真实默认值：

```js
material.defaultColors?.[colorIndex]
  || asset.DefaultColor?.[colorIndex]
  || "Default"
```

颜色面板中的重置只处理当前颜色，不会重置图层位置、偏移、透明度或隐藏状态。编辑器原有的“本层默认”仍负责恢复该层的全部编辑属性。

整体颜色操作会将所有颜色槽统一为确认的颜色。由于不同颜色槽可能拥有不同默认值，完整的多槽默认数组仍由编辑器的“整件默认”按钮恢复，避免用单个默认色错误覆盖整件素材。

### 面板背景与层级

BC 原版颜色面板通常依赖游戏画布作为视觉底色。COE 是独立浮层，直接复用时会出现透明背景与底部编辑器重叠。

COE 打开的颜色面板会临时添加：

```css
.coe-owned-color-picker
```

该类提供不透明浅灰蓝背景、边框和阴影，并临时提高面板层级。颜色面板关闭时立即移除该类并恢复原层级，因此不会改变游戏其他流程打开的原版颜色面板。

## 生命周期与兼容处理

- 同一时间只允许一个 COE 颜色选择会话；
- 若游戏已有可见颜色面板，不覆盖其状态；
- 只有点击确认才写回 `material.colors`；
- 取消不修改 COE 数据；
- 关闭 COE 时清理仍由 COE 持有的颜色面板；
- 回调写入前确认编辑器和当前方案仍然有效；
- 若未来 BC 版本不提供 `ColorPickerInit`，回退为颜色代码输入，接受 `#RGB`、`#RRGGBB` 和 `Default`。

## 修改位置

- `src/01-runtime.js`：颜色选择会话状态；
- `src/08-ui-shell.js`：颜色入口与原版面板不透明背景样式、关闭清理；
- `src/10-editor.js`：原版选择器接入、颜色规范化、整体与单层写回；
- `src/15-bootstrap.js`：测试接口；
- `tests/core.test.js`：原版入口、默认色、非透明背景与颜色规范化回归断言；
- `dist/CustomOutfitEditorEchoMirror.user.js`：同步后的可安装脚本。

## 验收结果

实机确认：

- 打开的确为游戏原版调色面板；
- 颜色代码输入、复制/粘贴、常用颜色和还原默认可用；
- 添加不透明背景后，面板不再与底部 COE UI 透叠；
- 其他颜色交互未发现问题。

第一轮颜色交互优化至此关闭。
