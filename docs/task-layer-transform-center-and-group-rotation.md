# 已废弃：可调变换中心设计

本文档描述的可调变换中心、中心拖拽、十字标记和相关持久化字段已从 COE-Echo-Mirror 移除。

当前实现只保留旋转、缩放和偏移：

- 单图层旋转、缩放与水平/垂直原地镜像优先围绕纹理 Alpha 有效内容包围盒中心；扫描未完成或失败时回退到纹理中点。
- 素材整体旋转、缩放与水平/垂直原地镜像只作用于同一 source Asset 的全部图层，使用该素材真实可见内容联合包围盒的自动中心；不会变换整个自定义方案。
- 编辑器不再显示中心输入、中心拖拽手柄或十字标记。
- 存储和远端协议不再包含可调中心字段。

请以 `docs/architecture.md` 和当前 `src/` 实现为准。
