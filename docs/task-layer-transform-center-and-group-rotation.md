# COE-Echo-Mirror 变换中心与整体旋转改造任务

> 状态：待落地
> 分支：`layer-transform`
> 当前基线提交：`54c3c02 修复图层旋转缩放中心坐标变换`
> 适用范围：开发阶段，无正式用户，不要求兼容历史用户数据

## 1. 背景

当前版本已经具备可用的单图层旋转与缩放功能，并已修复 WebGL 单位顶点坐标与纹理像素坐标混用导致的旋转中心偏移问题。

下一阶段需要完善变换中心和层级变换交互：

1. 单个图层可以拥有用户自定义的变换中心。
2. 旋转和缩放共用同一个中心。
3. 整体服装可以作为一个变换对象，让所有图层共同旋转和缩放。
4. 整体变换与单图层变换必须同时存在，互不覆盖。
5. 交互界面同一时间只显示一个变换编辑控件，避免所有图层同时出现十字准心和拖拽手柄。

本任务只要求落地上述设计，不要求维护正式用户的旧数据兼容链路。

---

## 2. 已确定的设计原则

### 2.1 旋转中心与缩放中心共用

无论作用对象是单图层、素材服装组还是整套服装，都只保存一个中心：

```text
pivotX
pivotY
```

该中心同时用于：

- 旋转
- 缩放

禁止设计成两个互相独立的字段，例如 `rotationPivot` 和 `scalePivot`。用户调整中心后，旋转和缩放都必须围绕同一点生效。

### 2.2 单图层中心与整体中心分属不同层级

单图层中心属于该图层的局部坐标空间：

```text
图层图片左上角 = (0, 0)
图层图片右下角 = (1, 1)
```

整体服装中心属于所有图层共同的合成坐标空间，不能使用某一张图片的局部百分比代替。

概念上的变换关系：

```text
最终图层结果 = 整体变换 × 单图层变换 × 原始图片
```

因此必须同时保留：

```text
整体旋转、整体缩放、整体中心
单图层旋转、单图层缩放、单图层中心
```

不能在用户执行整体旋转后，把整体角度烘焙进每个图层，也不能因为用户单独旋转某个图层而重建整体中心。

### 2.3 默认整体中心

整件服装或目标素材服装组的默认中心，使用可见内容包围盒最大的图层作为中心参考。

这里的“最大图层”应优先理解为：

> 实际可见内容包围盒最大的图层，而不是 PNG 原始宽高最大的图层。

如果无法取得实际 alpha 包围盒，可以使用当前可用的纹理尺寸作为降级方案，但需要保持结果稳定。

默认中心只在用户没有手动调整时使用。一旦用户手动设置中心，应保存用户值，不要在每次重绘或重新加载时自动覆盖。

### 2.4 允许中心位于图层外部

中心不应强制限制在图层矩形内部。手持物、翅膀、长鞭等对象可能需要绕图片外部的连接点旋转。

建议逻辑允许中心超出 `[0, 1]`，但 UI 拖拽范围可以设置合理边界，避免控件被拖到完全不可用的位置。

## 3. 数据模型要求

### 3.1 单图层变换

单图层应具备以下概念字段：

```text
rotation
scale
offsetX
offsetY
pivotX
pivotY
```

其中：

- `rotation`：弧度或项目当前统一采用的角度表示
- `scale`：当前项目使用的统一缩放比例
- `offsetX / offsetY`：图层在合成空间中的位置偏移
- `pivotX / pivotY`：相对于该图层纹理的局部中心

### 3.2 整体服装变换

整体变换属于配置或合成级别，不属于某个单独材质或图层。

建议具备以下概念字段：

```text
overallRotation
overallScale
overallOffsetX
overallOffsetY
overallPivotX
overallPivotY
```

即使第一阶段只开放整体旋转，也应避免把整体字段混入单图层字段。这样后续加入整体缩放和整体偏移时不需要再次重构数据层级。

### 3.3 默认值与序列化

建议默认值不序列化：

```text
rotation = 0
scale = 1
overallRotation = 0
overallScale = 1
pivotX = 默认中心
pivotY = 默认中心
```

用户没有手动修改中心时，可以不写入 `pivotX / pivotY`，加载时重新得到默认中心。

用户手动修改后才保存中心值。

### 3.4 开发期数据迁移策略

当前插件没有正式用户，不要设计旧版本兼容体系，也不要保留多套历史字段转换逻辑。

采用一次性数据过滤和重建：

1. 读取当前配置。
2. 检查素材服装是否存在。
3. 删除不存在、损坏或无法重新绑定的素材和图层。
4. 根据当前 Asset 数据重新建立 material 和 layer。
5. 只复用明确允许复用的视觉字段。
6. 未知字段直接丢弃。
7. 使用当前数据结构重新保存。

可以复用的字段包括：

```text
图层顺序
优先级
偏移
隐藏状态
清除状态
颜色
透明度
旋转角度
缩放比例
pivotX / pivotY
```

如果素材身份或图层身份无法确认，应删除该图层，不要尝试绑定到近似素材。

图层身份优先使用：

```text
sourceGroup
sourceAsset
sourceLayerIndex
sourceLayer
```

索引与名称不一致时，应以当前数据安全为优先，放弃无法确认的旧图层。

### 3.5 远程协议

由于当前没有正式用户，远程协议可以直接按新数据结构更新，不需要维护旧版远程兼容。

如果当前协议采用严格字段白名单，应同步更新：

- 快照层字段校验
- 快照规范化
- 本地快照生成
- 远程快照读取
- 远程渲染字段传递
- 规范化哈希计算
- 相关测试

可以使用简短字段，例如：

```text
px
py
```

但字段含义必须在协议文档中明确。若协议版本用于隔离结构变化，可以直接提升当前协议版本。

## 4. 交互设计要求

### 4.1 不让所有图层同时显示控件

任何时候只允许一个变换编辑目标处于激活状态。

未激活图层不得显示：

- 旋转中心十字准心
- 旋转拖拽手柄
- 缩放拖拽手柄
- 变换操作边界

普通状态可以保留图层选择效果，但不要显示完整变换控件。

### 4.2 旋转和缩放参数不必完全隐藏

建议区分普通参数和高级中心编辑：

普通编辑区保留：

```text
旋转角度
缩放比例
偏移
重置变换
```

高级交互通过按钮显式开启：

```text
调整旋转中心
```

进入中心编辑模式后，才显示当前目标的：

- 中心十字
- 旋转拖拽手柄
- 缩放拖拽手柄
- 变换边界
- 当前中心坐标
- 重置中心按钮

退出中心编辑模式后，所有可视化控件消失，但数据保留。

### 4.3 编辑目标

至少支持以下两种目标：

```text
当前图层
素材服装组整体
```

如果当前项目已有“整套配置”级别选择器，可额外支持整套服装，但不应让三种层级同时处于模糊状态。

用户必须能够清楚知道当前正在编辑：

```text
图层旋转中心
素材组整体旋转中心
整套服装旋转中心
```

推荐通过目标选择器或明确的状态文字提示当前目标。

### 4.4 单图层编辑流程

```text
1. 用户选中一个图层。
2. 点击“调整旋转中心”。
3. 只显示该图层的变换控件。
4. 用户拖动中心或旋转/缩放手柄。
5. 旋转与缩放始终围绕同一个 pivot。
6. 用户点击完成、点击外部或按 Escape 退出。
7. 保存该图层的变换参数。
```

### 4.5 素材组整体编辑流程

```text
1. 用户将变换目标切换为“素材服装组整体”。
2. 只显示该组的整体中心和整体变换控件。
3. 该组所有图层一起旋转或缩放。
4. 各图层的局部中心不显示。
5. 用户退出后，整体变换仍保留。
```

### 4.6 交互锁定

一次拖拽开始后，应锁定当前目标，直到鼠标或触控操作结束。

拖拽过程中点击其它图层不应导致当前目标突然切换。用户切换目标时，应先结束当前中心编辑状态，再激活新目标。

不建议为普通目标切换增加频繁弹窗确认。

### 4.7 中心点视觉区分

如果需要区分层级，可以使用不同视觉样式：

```text
单图层中心：小型蓝色十字
素材组整体中心：较大的橙色十字
```

但任何时候仍只显示当前激活目标的一个中心。

## 5. 变换语义

### 5.1 操作顺序不应影响结果语义

以下两种操作顺序都应该得到稳定的数据：

```text
先整体旋转，再单独旋转图层
先单独旋转图层，再整体旋转
```

整体旋转角度和单图层旋转角度始终分别保存。

例如：

```text
整体旋转：20°
整体中心：腰部

帽子局部旋转：15°
帽子局部中心：帽顶
```

修改整体角度时，帽子的局部中心和局部角度不能被覆盖。

### 5.2 修改整体中心的效果

修改整体中心后，所有图层的整体旋转和整体缩放轨迹都会改变，这是正常且预期的行为。

单图层中心不应因此发生改变。

### 5.3 修改单图层中心的效果

修改单图层中心后，只影响该图层的局部旋转和局部缩放轨迹。

整体中心和其它图层不应发生改变。

### 5.4 重置行为

至少需要区分：

```text
重置当前图层变换
重置整体服装变换
重置当前中心
恢复默认中心
```

“恢复默认中心”应恢复最大可见内容图层提供的默认中心，而不一定等于当前图片的几何中心。

---

## 6. 重要实现约束

1. 单图层 pivot 使用图层局部坐标。
2. 整体 pivot 使用共同合成坐标。
3. 不要用某个图层的纹理中心代替整体中心。
4. 不要把整体角度烘焙进单图层角度。
5. 不要把单图层角度反向推导成整体角度。
6. 旋转和缩放必须共享 pivot。
7. 变换控件只能绑定一个当前编辑目标。
8. 未激活图层不能拦截变换拖拽事件。
9. 默认中心只在没有用户自定义值时计算。
10. 用户设置过的中心不能被每帧自动算法覆盖。
11. 本地配置和远程快照必须使用同一套变换语义。
12. 远程渲染不能只同步角度和缩放而遗漏 pivot。

---

## 7. 测试重点

### 数据

- 旧配置缺少 pivot 时能够加载并使用默认中心。
- 非法 pivot 类型会回退到默认值。
- 超出允许范围的 pivot 按当前策略处理。
- 用户修改 pivot 后能够保存并重新读取。
- 未修改默认中心时不会产生不必要的序列化字段。
- 不存在的素材会被过滤。
- 无法确认的图层不会错误绑定到其它素材。
- 颜色、隐藏状态、清除状态、偏移和优先级能够在重建后保留。

### 渲染

- 单图层旋转围绕自定义 pivot。
- 单图层缩放围绕同一个 pivot。
- 旋转与缩放同时存在时仍围绕同一点。
- 整体旋转时所有图层保持相互位置关系。
- 整体缩放时所有图层保持相互位置关系。
- 单图层局部旋转不会改变其它图层。
- 整体变换不会覆盖单图层变换。
- 镜像、反转与整体/局部变换组合时不出现方向错误。
- 旋转中心变化不会导致未操作图层发生额外偏移。

### 交互

- 默认只显示当前激活目标的一个中心控件。
- 切换图层后不会残留旧图层控件。
- 切换到素材组整体后不会同时显示所有子图层中心。
- 拖拽过程中目标不会突然切换。
- 点击退出、点击外部、按 Escape 后控件正确隐藏。
- 旋转和缩放控件均围绕同一个中心工作。
- 重置当前图层不会重置整体服装。
- 重置整体服装不会重置单图层设置。

### 远程

- 新字段能够进入规范化快照。
- 本地发送和远程接收的 pivot 值一致。
- 远程图层的旋转与缩放中心和本地一致。
- 快照哈希包含 pivot 差异。
- 协议严格校验不会意外放行非法 pivot。

## 8. 非目标

本任务暂不要求：

- 兼容正式用户的历史数据。
- 维护多个历史版本字段。
- 自动识别服装语义连接点。
- 自动判断“腰部、肩部、手部”等真实穿戴锚点。
- 同时显示所有图层的变换控件。
- 为旋转中心和缩放中心分别设计两套数据。
- 将整体变换烘焙为单图层变换。
- 一开始就实现复杂的三维或透视变换。

---

## 9. 推荐落地顺序

1. 先确认当前单图层旋转与缩放的基线行为。
2. 引入单图层共享 pivot。
3. 完成单图层中心的保存、读取和默认中心计算。
4. 完成单图层中心编辑交互。
5. 增加素材服装组整体变换数据。
6. 实现整体变换与单图层变换的层级叠加。
7. 实现整体中心默认取最大可见内容图层。
8. 实现整体中心手动编辑。
9. 实现单目标变换控件和目标切换。
10. 更新远程快照与协议校验。
11. 完成本地、远程、交互和组合变换测试。
12. 重新构建 dist 并进行实际测试服装验证。

---

## 10. 完成标准

满足以下条件后，任务可视为完成：

- 用户可以调整单独图层的中心。
- 用户可以调整素材服装组整体中心。
- 旋转和缩放使用同一个中心。
- 单图层变换与整体变换可以同时存在。
- 两种变换不会互相覆盖或污染数据。
- 同一时间只出现一个目标的变换控件。
- 默认整体中心来自最大可见内容图层。
- 用户手动设置中心后不会被自动逻辑覆盖。
- 配置可以按当前数据结构正常保存和重新加载。
- 远程发送与接收使用同一套中心语义。
- 所有既有旋转与缩放测试保持通过。
